1 · OVERVIEW

先对齐：这游戏到底是什么循环

单局 Roguelike 卡牌构筑（Deckbuilding Roguelike）：爬塔一局 = 一条 RUN
一局（RUN）的宏观循环
涅奥开局祝福→ 第 1 幕 地图选路↻ 战斗/事件/商店/篝火→ 幕 BOSS→ 下一幕→ 第 3 幕 BOSS→ 结局 / 心脏(第4幕)
单场战斗的回合循环（两代通用）
回合开始
能量重置3 · 抽5张 · 结算回合开始效果→ 玩家出牌
消耗能量 · 攻击/技能/能力→ 点结束回合
弃掉手牌 · 结算遗物→Buff→卡牌效果→ 敌人行动
按上方意图逐个结算（左→右）↻
构筑循环：卡组怎么变强
  • 战斗胜利 → 卡牌奖励 3 选 1（或跳过）
  • 商店 → 买卡 / 买遗物 / 删卡（卡组瘦身同样是构筑）
  • 篝火 → 升级卡牌（+数值强化）或休息回血 30%
  • 事件 → 高风险高回报：换血、拿诅咒换奖励、删卡……
  • 核心张力：删卡 > 选卡 > 升卡 —— 卡组越小越稳定，这是本游戏构筑论的基石

伤害 & 格挡公式（多段攻击每段独立计算）

攻击伤害 = floor( ( 基础伤害 + 力量(Strength) ) × 易伤(Vulnerable) × 虚弱(Weak) ) ; 其中 易伤 = 1.5（纸青蛙 1.75） · 虚弱 = 0.75（纸鹤 0.60）
格挡值 = floor( ( 基础格挡 + 敏捷(Dexterity) ) × 脆弱(Frail)0.75 )

关键细节：StS1 中不存在无视格挡的攻击；绕过格挡的全部是 HP 直接损失类（中毒/灼烧/Beat of Death/HP 交换类）。这两类伤害在复刻时必须走不同的结算管线。格挡在玩家回合开始时清零。

牌堆状态机 —— 复刻的核心数据结构

抽牌堆 Draw⇄ 抽牌 手牌 Hand (≤10)打出/弃置 → 弃牌堆 Discard ; 弃牌堆 ↩ 洗回（仅当抽牌堆被抽空时整体洗回）
  • 能力(Power)卡打出后彻底消失，不进任何堆 —— 状态机里要有第四个隐式去处「在场效果」
  • 消耗(Exhaust)卡进消耗堆，不参与洗牌；全游戏唯一回收手段是卡牌 Exhume
  • 回合结束的结算顺序有讲究：遗物 → Buff → 卡牌（例：山铜先于镀层装甲先于灼烧）—— 复刻要按固定管线顺序触发

Buff/Debuff：三层属性模型

研究文档将全部状态效果归纳为 强度(Intensity) / 持续(Duration) / 计数(Counter) 三层模型 —— 比逐个硬编码更适合做数据驱动。例如：

力量 力量层数 = 攻击伤害加值（强度型） 易伤 受伤×1.5（持续 N 回合） 虚弱 造成伤害×0.75（持续 N） 中毒 回合开始掉等量 HP 后层数−1（唯一双属性 debuff） 再生 回合开始回 HP 后层数−1（唯一双属性 buff） 金属化 回合结束获得 N 格挡 Shackled "Debuff 壳 + Buff 逻辑"的实现陷阱

完整清单（含约 20 个敌人专属 Buff）和全部关键词（消耗/虚无/固有/保留/预见 Scry/X 费）见文档 §2.4、§6。

8 · WEB CLONE NOTES

面向网页复刻的落点 —— 我从资料里读出的开发蓝图

这一节是理解深度的自证：能否把研究变成可实现的设计

复刻顺序建议

  • 先做 1 代：数值稳定、资料完备（社区连地图生成算法都逆向了），是这套玩法的"公理全集"
  • 架构数据驱动：卡牌/遗物/敌人/事件全部走表结构（JSON），引擎核心两代共用
  • 2 代按 v0.107.1 反编译快照建模，版本易变字段（数值/BOSS/Ancients 池）隔离成版本化数据层，2026-11-12 大补丁后复核
  • 引擎核心优先级（两代交集）：回合状态机 → 牌堆状态机 → 意图系统 → 地图生成 → 事件系统 → 商店/篝火 → 药水 → 升阶
  • 2 代专属系统延后：附魔、任务卡、Ancients、交替区域、联机（复刻成本极高，首期不做）

最容易被写错的 8 个系统（资料里挖出来的坑）

① 牌堆状态机

弃牌堆只在抽牌堆抽空时整体洗回；Power 卡打出后消失（第四去处）；Exhume 是唯一回收消耗堆的手段。

② 回合结束触发顺序

遗物 → Buff → 卡牌（山铜 > 镀层装甲 > 灼烧）。自由发挥顺序会产生规则级 bug。

③ 两类伤害管线

攻击伤害吃格挡/易伤/虚弱/力量；HP 损失类（中毒/灼烧/Beat of Death）全部绕过 —— 必须分开结算。

④ 意图可被中断重算

12 种触发器（血量阈值/受击/分裂/重生…）。BOSS AI = 8 种建模原语的组合，不是简单循环。

⑤ 卡牌奖励的隐藏偏移

稀有率起点 −5%、每张普通 +1%、出稀有重置 → 每幕首层不可能出稀有。直接抄基准概率会复刻出错误手感。

⑥ 寂静猎手起始 12 张

不是 10 张。同理各角色起始遗物/HP 逐项核对过，别按"常识"写。

⑦ 观者姿态 ×2 是双向

Wrath 打人 ×2 也被打 ×2；Calm 退出回 2 能量（紫莲 3）；Divinity 下回合开始自动退出。

⑧ 时间吞噬者类反制

玩家每打 12 张牌 → 敌人 +2 力量且强制结束玩家回合。敌人要能反向操作玩家回合 —— 引擎需支持。
