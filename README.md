# 杀戮尖塔 (Slay the Spire) 1 & 2 — 网页复刻前期资料

> 目标：系统性收集《杀戮尖塔》1 代与 2 代（抢先体验）的**全部实体数据与机制规则**，
> 作为网页复刻项目的设计与数据基础。

## 架构：一套数据 + 一个 UI

```
data/sts1/*.json + data/sts2/*.json   ← 底层数据库（复刻项目直接 import）
        │
        ▼  python3 review/build.py（代理每落地一批 JSON 就重跑一次）
review/data.js                         ← 打包后的单一数据源
        │
        ▼
review/index.html                      ← 统一展示层：检索 / 筛选 / 展开
   深链格式：#db/<game>/<entity>，如 #db/sts1/cards、#db/sts2/enemies
```

## Review 网页

`review/index.html`：单文件、离线可用、白底浅色。三个 Tab（1 代 / 2 代 / 实体数据库），
左侧目录 + 顶部阅读进度条；每个游戏页底部有各实体表的直连链接；
实体数据库支持关键词检索、稀有度/角色/幕/层级筛选、行点击展开（敌人招式、事件选项、古代祝福）。

## 注意事项

- StS2 处于 EA，数值随补丁变动：**2026-11-12 大补丁后所有 `data/sts2/` 需复核一遍**。
- StS2 中文译名为项目自拟（官方未发布中文）；StS1 卡牌中文名经官方简中本地化文件交叉校验。
- 所有文档文末列参考来源与不确定项标注；地图生成规则等社区逆向内容标记 [RE]。
