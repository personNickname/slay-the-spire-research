# 杀戮尖塔 (Slay the Spire) 1 & 2 — 网页复刻前期资料

> 目标：系统性收集《杀戮尖塔》1 代与 2 代（抢先体验）的机制、内容、角色资料，
> 作为后续网页版复刻项目的设计与数据基础。

## 目录结构

```
slay-the-spire-research/
├── README.md                  # 本文件：总览导航
├── docs/
│   ├── sts1/                  # 杀戮尖塔 1 代
│   │   ├── core-mechanics.md      # 战斗核心机制（能量/卡牌/格挡/Buff/伤害公式）
│   │   ├── characters.md          # 四角色（铁甲战士/寂静猎手/故障机器人/观者）
│   │   ├── map-events-shop.md     # 地图结构/事件/商店/篝火/升阶/解锁
│   │   └── enemies.md             # 敌人/精英/BOSS 行为模式与意图系统
│   ├── sts2/                  # 杀戮尖塔 2 代（EA）
│   │   ├── overview.md            # 概况：版本状态/路线图/已实装内容
│   │   ├── core-mechanics.md      # 核心机制与代际差异
│   │   ├── characters.md          # 已实装角色详表
│   │   └── content.md             # 敌人/事件/遗物/内容规模
│   └── comparison.md          # 1 代 vs 2 代总对比
└── review/
    └── index.html             # 评审网页：可视化展示全部研究结论
```

## 如何 Review

直接用浏览器打开 `review/index.html`（单文件、无外部依赖、离线可用）。
页面包含：两代总览、核心机制、角色、敌人、地图事件、内容规模对比，
以及"网页复刻开发要点"清单。

## 资料说明

- 文档为中文撰写，游戏术语保留英文原文对照（便于开发时命名数据字段）。
- 数值（能量、血量、倍率、价格等）优先取自官方与社区 wiki，来源列在各文档文末。
- 2 代处于抢先体验，信息标注了对应版本/日期（资料截至 2026-11）。
