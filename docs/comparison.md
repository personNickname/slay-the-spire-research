# 《杀戮尖塔》1 代 vs 2 代 总对比

> 汇总自本目录其余 8 份研究文档（StS1 四份 + StS2 四份），检索/查证日期 2026-11-09。
> 2 代处于抢先体验(EA)，当前主线版本 v0.107.1 / Beta v0.111.0，机制随补丁变动，对比以该版本为准。

## 1. 产品与版本状态

| 维度 | 杀戮尖塔 1 (2019 正式版) | 杀戮尖塔 2 (EA) |
|---|---|---|
| 开发/发行 | Mega Crit | Mega Crit |
| 引擎 | libGDX (Java) | Godot |
| 发布 | 2017 EA → 2019-01 正式版（Win/Mac/Linux/主机/移动） | 2026-03-05 EA（原计划 2025 年底，2025-09-11 官宣延期），Win/Mac/Linux，$24.99 |
| 当前版本 | 内容稳定（1.0 + 少量平衡补丁） | 主线 v0.107.1（2026-06-18 Major Update #2），Beta v0.111.0；下一大补丁 2026-11-12 上 Beta |
| 完整版预估 | — | 官方称 EA 1-2 年，外媒推测 1.0 约 2027 |
| 模组 | 官方支持 + 社区 BaseMod/ModTheSpire | v0.107.1 起 Steam 创意工坊原生支持 |
| 联机 | 无 | 4 人合作（好友制，无匹配），联机敌人血量/伤害缩放 |

## 3. 核心机制差异

| 系统 | StS1 | StS2 |
|---|---|---|
| 能量/抽牌/手牌 | 3 能量、抽 5、手牌上限 10 | 同（社区推定，官方未发布文档；升阶 4 文本反推一致） |
| 伤害公式 | floor((基础+力量)×易伤1.5×虚弱0.75)，多段独立结算 | 公式框架保留（数值待实机核验） |
| BOSS 遗物 | 击败幕 BOSS 后三选一（代价型遗物，如 So Beautiful/Philosopher's Stone） | **被 Ancients 祝福系统取代**：开局 Neow 三选一（2 正面 + 1 诅咒遗物），每幕古代节点（8 位古代：Neow/Orobas/Pael/Tezcatara/Nonupeipe/Tanx/Vakuu/Darv），祝福带代价（黄金单路、蜡遗物倒计时、不可移除降费 Strike 等） |
| 卡牌修饰 | 无 | **附魔(Enchantment)**：整局卡牌修饰（Sharp/Favored/Corrupted/Imbued/Replay 等 16+），官方明令禁止叠加 |
| 新卡牌类型 | 状态/诅咒 | + **任务卡(Quest)**（如 Byrdonis 蛋：休息处孵化战斗鸟）、折磨(Affliction，敌方塞入的污染卡） |
| 药水 | 3 槽（A11 为 2），42 种 | 64 种（普通/非凡/稀有/特殊 = 20/20/20/4，每角色专属 1 种），有"追踪遗物与药水更易"的 UI 辅助 |
| 升阶 | **1-20 级**（内容庞大：精英概率、血量、伤害、起始降 HP、少药水槽、诅咒、Boss 遗物变少等逐级叠加） | **压缩为 1-10 级**（A5 起 Ascender's Bane，A8 敌人强化，A9 攻击强化，A10 三幕双 BOSS；官方称 10 级即接近上限） |
| RNG | 内置 | v0.107.1 重构为 xoshiro256** |

## 7. 对网页复刻的策略建议

1. **先复刻 1 代**：资料完备（社区 wiki 数值精确、社区已逆向地图生成算法），内容稳定不变动；1 代也是该玩法公理体系的最小完备集。
2. **架构上为 2 代留扩展**：数据驱动（卡牌/遗物/敌人/事件全部表结构化）；引擎核心（回合状态机、牌堆状态机、意图系统）两代通用。
3. **2 代按 v0.107.1 反编译快照建模**，但把"随版本变动"的字段（数值、BOSS、Ancients 池）隔离成版本化数据层；2026-11-12 大补丁后需重新核对。
4. **通用系统优先级**（两代交集）：回合状态机 → 牌堆状态机 → 意图系统 → 地图生成 → 事件系统 → 商店/篝火 → 药水 → 升阶。
5. **仅 2 代需要的系统**延后：附魔、任务卡、Ancients、交替区域、合作模式（联机复刻成本极高，建议首期不做）。
