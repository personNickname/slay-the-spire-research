# 《杀戮尖塔 1》敌人（Enemies）全览 —— 网页复刻研究文档

> 数据基准：正式版（Steam v2.x，含 Watcher 与第四幕），数值取自 slaythespire.wiki.gg 各敌人页面（2026-11 查证）。
> 约定：`A` = 进阶等级(Ascension)。文中数值默认为 A0 基础值，括号内为进阶强化值，如 `11（A2+：12）` 表示进阶 2 起 12 点伤害；血量列为 `基础（进阶后）`。
> 通用进阶档位（wiki 各敌人页招式标注归纳）：普通敌人伤害 A2 起提升、A17 起再提升；精英伤害 A3 / A18；BOSS 伤害 A4 / A19；血量亦有对应提升（wiki 页面的 AscHP 字段）。

## 1. 意图(Intent)系统

### 1.1 图标含义

| 图标 | 含义 | 备注 |
| --- | --- | --- |
| 攻击(Attack)（剑形） | 下回合进行攻击 | 剑的样式按单段伤害分 7 档：0-4 / 5-9 / 10-14 / 15-19 / 20-24 / 25-29 / ≥30 |
| 多段攻击 | 同上，显示"每段伤害×段数"（如 5×4） | 游戏内并非独立图标，攻击图标旁附带段数；对多段攻击每段单独结算格挡(Block)与力量(Strength) |
| 格挡(Defend)（盾形） | 下回合获得格挡(Block) | |
| 增益(Buff)（上箭头） | 下回合获得增益 | 例外：秘术师(Mystic)、时间吞噬者(Time Eater)、暗灵(Darkling) 用增益图标表示**治疗** |

| 组合图标 | 攻击+格挡、攻击+减益、攻击+增益、格挡+减益、格挡+增益 | 武器部分档位随伤害变化 |
| 逃跑(Escape) | 本回合逃离战斗 | 掠夺者(Looter)偷金后逃跑 |
| 睡眠(Sleep)（zzz） | 本回合不行动 | 拉格维林(Lagavulin)初始状态 |
| 眩晕(Stunned)（螺旋） | 本回合不行动 | 见 1.3"意图中断" |
| 未知(Unknown)（?） | 内容不定 | 具体用途：分裂(Split，大史莱姆/史莱姆老大)、爆炸(Explode，爆炸者 Exploder)、召唤仆从、重生(Rebirth，觉醒者)、以及"什么都不做"的蓄力/准备类招式 |

### 1.2 显示规则

- 敌人意图在其回合结束后、你的回合开始时生成并显示在敌人头顶，代表它**下回合**的行动（来源：Intent 词条）。
- 攻击意图上显示的数字为预计造成的伤害，**随敌人力量(Strength)、虚弱(Weak)/易伤(Vulnerable)等状态实时修正**，但**不扣除你当前的格挡(Block)**（社区通识，wiki.gg Intent 页未逐字写明，见文末"不确定项"）。
- 遗物(Relic) 符文圆顶(Runic Dome)：所有意图一律显示为"未知"，作为补偿每回合+1 能量(Energy)。
- 玩家**没有**任何眩晕(Stun)敌人的卡牌/手段；"眩晕"仅作为敌人自身状态出现（见 1.3）。

### 1.3 意图中断 / 打断机制（复刻实现要点）

意图通常在生成后保持到敌人行动，但存在以下"中途改写"来源（均为 wiki 逐页查证）：

| 触发条件 | 敌人 | 意图变化 |
| --- | --- | --- |
| 血量 ≤50% | 大史莱姆(Spike/Acid Slime L)、史莱姆老大(Slime Boss) | 当前意图立即改为"分裂(Split)"（未知图标），下回合消失并分裂 |
| 本回合累计失去 30 HP（进阶 A9+：35 / A19+：40，每次触发+10） | 守护者(The Guardian) | 触发模式转换(Mode Shift)：获得 20 格挡，当前意图替换为防御模式 |
| 血量降至 0（第一形态） | 觉醒者(Awakened One) | 意图变为"重生(Rebirth)"（未知图标），满血复活进入二阶段 |
| 血量 <50% 的下一回合 | 冠军(The Champ) | 使用"愤怒(Anger)"进入二阶段（移除全部减益+力量） |
| 血量 <50% 时（每次战斗一次） | 时间吞噬者(Time Eater) | 使用"急速(Haste)"：移除全部减益、回血至 50% |
| 受到任何伤害（睡眠中） | 拉格维林(Lagavulin) | 睡眠中断，眩晕 1 回合后开始攻击；若 3 回合未被伤害则自行醒来（移除金属化） |
| 一回合内被攻击命中 3 次（飞行(Flying)被击落） | 飞鸟(Byrd) | 当前意图替换为"眩晕"，随后 轻撞(3) → 重新起飞(Back Airborne，+3 飞行) |

| 死亡时仍有同伴存活 | 暗灵(Darkling) | 意图变为"再生中…"（不可被指定），2 回合后以 50% 血量复活 |
| 受到攻击伤害时（每回合随机） | 蠕动物质(Writhing Mass) | 特有能力"应激(Reactive)"：每次被攻击命中即**随机重掷**当前意图 |
| 血量≤50% 阈值 | 见上表史莱姆类 | —— |

循环：盾在两次碾压之间交替 痛击→强化 或 强化→痛击（50/50）；矛在两次穿刺之间交替 灼烧打击→钻头 或 钻头→灼烧打击。意图规律：固定回合号大招（盾 3、6、9…；矛 2、5、8…）+ 间隙两步循环——可通过数回合精确预知。

## 7. 跨幕规律总结（复刻建模清单）

| 行为模型 | 敌人示例 | 建模方式 |
| --- | --- | --- |
| 固定循环 | 哨卫、青铜自动机、六火幽灵、史莱姆老大、多努/德卡、爆炸者、匕首 | 数组循环 + 起手式偏移 |
| 概率循环（带"不连用 N 次"约束） | 颚虫、真菌兽、蓝色奴隶贩子、刺击之书、时间吞噬者、觉醒者 | 每回合按权重表掷点，拒绝非法重复并重掷 |
| 马尔可夫链（按上一招转移） | 颚虫、史莱姆（大）、蠕动物质（概率随上一招变化的转移矩阵） | 状态转移表 |
| 固定回合号大招 | 冠军（每 4 回合嘲讽）、尖塔之盾（3,6,9…碾压）、尖塔之矛（2,5,8…穿刺）、腐化之心（4,7,10…增益） | 回合计数器 |
| 血量阈值阶段切换 | 史莱姆老大（50%分裂）、冠军（50%愤怒）、时间吞噬者（50%急速）、觉醒者（0 血重生）、守护者（失血 30 模式转换） | HP 监听器即时改写意图 |
| 回合数衰减/成长 | 转瞬即逝者（+10×回合数）、刺击之书（使用计数）、巨头（使用计数上限 60）、巨口（回合数） | 战斗内计数器 |
| 玩家行为反制 | 诺布（技能牌）、觉醒者（能力牌）、时间吞噬者（打牌数）、守护者防御模式（攻击牌）、蜥蜴术士（间接伤害绕过无形/飞行） | 出牌钩子 |
| 场面状态驱动 | 哥布林头目（按场上仆从数切换概率表）、收集者（按火把头存活数）、百夫长（秘术师死亡换技能） | 战场状态查询 |
